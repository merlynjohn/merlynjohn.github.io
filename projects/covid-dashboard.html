COVID-19 Dashboard
Insights & Trends

An interactive dashboard exploring COVID-19 cases, deaths, recoveries, and trends over time.

Overview

This project explores global COVID-19 data to identify patterns and trends in cases, deaths, and recoveries. The analysis was developed in a Jupyter Notebook and presented through interactive visualisations.

How it works

The project was developed in a Jupyter Notebook using Python and Pandas for data preparation and analysis, with Plotly used to create interactive visualisations. Voilà was then used to run the notebook as an interactive dashboard through a web interface.

What I did

  • Cleaned and prepared the COVID-19 dataset.
  • Analysed COVID-19 cases, deaths, and recoveries across different regions and time periods.
  • Identified patterns and trends in the data.
  • Created interactive visualisations using Plotly.
  • Developed the analysis in a Jupyter Notebook.
  • Used Voilà to turn the notebook into an interactive dashboard.

Tools

Python · Pandas · Plotly · Jupyter Notebook · Voilà
